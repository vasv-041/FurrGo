# FurrGo

- [x] Shared persistent state built only from what the user logs (no seeded/sample numbers)
- [x] Draggable, tappable panda that reacts, with position remembered
- [x] Logging flow for steps, sleep, workouts, medication, goals and name
- [x] Gamified and Clean experiences over the same logged data
- [x] Empty states everywhere before anything is logged
- [x] Clear-all-data control in Profile
- [x] Interactive room spots (bed, window, plant, water, mat, story shelf, lantern, visiting friend) that move and react the panda, unlocking with Bond XP
- [x] Unlockable story chapters in a Pet "Stories" tab, earned through XP, streaks and logged days
