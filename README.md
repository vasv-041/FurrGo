# 🐾 AI Health Companion

An AI-powered healthcare monitoring assistant that combines **fitness tracking, medication management, medical report simplification, and a virtual pet** to make health monitoring more engaging and understandable.

## 🎯 Problem

Healthcare apps often provide data and reminders but can be difficult to understand and easy to ignore. Users may also struggle with complex medical terminology.

## 💡 Solution

AI Health Companion provides:

- 🐾 Virtual pet that reacts to healthy habits
- 🚶 Fitness tracking (steps, sleep, activity)
- 💊 Medication schedules and reminders
- 🤖 AI-powered general health assistant
- 📄 Medical report & prescription explanation in simple language
- 📊 Weekly AI-generated health summaries
- ⭐ XP, levels and streaks for engagement

## 🛠️ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Python + FastAPI
- **AI:** Google Gemini API
- **Database:** Firebase Firestore
- **Fitness:** Google Fit / supported fitness API
- **Pet Animation:** Rive / Lottie
- **Version Control:** Git + GitHub
